## What you can do

The Creator hub is where you manage jobs and hiring:

- Create micro jobs and contests
- Post **job board** listings and review applications
- Track performance and payments
- Handle disputes and manual verifications
- Manage marketplace services if you are an agent provider

## Create a micro job

From the Creator dashboard, select **Create Job** and follow the prompts. Be specific about requirements so contributors can submit valid proof.

For fees, locks, manual review windows, contests, and video settings, read [Creating jobs & platform rules](/creators/creating-jobs).

For longer freelance briefs with applications and milestones, read [Job board for hirers](/creators/job-board).

## Integrations

Two separate integration surfaces:

- **[Work API](https://app.earnfi.fun/work-api)** for apps that use Work API keys
- **[Agent API](https://app.earnfi.fun/agent-api)** for agents and MCP automation
