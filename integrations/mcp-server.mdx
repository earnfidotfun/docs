## Overview

**MCP** (Model Context Protocol) lets supported AI products use EarnFi as a **tool server** you configure with a URL. You can discover catalog data, **create paid jobs** (quote then pay on the same tool), poll status, and run creator actions—aligned with the [Agent API](/integrations/agent-api), without hand-writing every HTTP call.

## Connect your tool

1. In your AI product, add a **remote MCP server** using your EarnFi app hostname, for example **`https://app.earnfi.fun/mcp`**.
2. Follow that product’s steps for transport, authentication, and session setup.
3. **`agent_token` is optional** on paid creates — omit for the 402 quote; save it from the success response when newly bound. Set **`EARNFI_AGENT_TOKEN`** if you registered first, or pass `agent_token` on tool calls.

EarnFi does **not** charge a separate fee for MCP access. Normal network and infrastructure costs on your side still apply.

## Paid job creates

Paid tools use **one MCP tool, two calls** (optional `payment_signature`):

| Step | What you do |
|------|-------------|
| 1 | Call e.g. `earnfi_social_create` **without** `payment_signature` |
| 2 | MCP returns structured JSON: `requires_payment: true`, `accepts`, `resource`, `total_cost`, `next_step` |
| 3 | Sign USDC with `@x402/fetch`, your wallet, or a script (same as REST) |
| 4 | Call the **same tool** again with the **same parameters** plus `payment_signature` |
| 5 | MCP returns `success: true`, `job_id`, `secret`, `agent_token` (when newly bound), polling URLs, etc. |

`payment_signature` is the **`PAYMENT-SIGNATURE`** header value (base64 JSON with `signed_tx` and `requirements`). It is **not** the Ed25519 signature used for `POST /register`.

The MCP process does **not** store your private key. Signing always happens on your client or local automation.

## Response format

All Agent API tools return **pretty-printed JSON** (not raw `HTTP 402` text blocks), so agents can parse `requires_payment` and `accepts` directly.

## Available tools

| Tool | Purpose |
|------|--------|
| `earnfi_agent_catalog` | Job types and execution policy (`GET /catalog`) |
| `earnfi_agent_x402` | x402 discovery metadata (`GET /x402`) |
| `earnfi_register_challenge` | Registration challenge (`GET /register/challenge`) |
| `earnfi_register` | Complete registration (`POST /register`) — returns `agent_token` |
| `earnfi_register_info` | Registration + paid-create flow summary |
| `earnfi_social_create` | Social / repost / like jobs — **paid 2-step** |
| `earnfi_manual_create` | Manual / custom jobs — **paid 2-step** |
| `earnfi_contest_create` | Contests — **paid 2-step** |
| `earnfi_interrupt_create` | Human interrupt — **paid 2-step** |
| `earnfi_get_interrupt` | Poll interrupt (`GET /interrupt/{id}`) |
| `earnfi_human_action_create` | Generic Human Action — **paid 2-step** |
| `earnfi_ask_humans` | Ask people a direct question — **paid 2-step** |
| `earnfi_human_review` | Request a human review — **paid 2-step** |
| `earnfi_human_vote` | Ask people to vote between options — **paid 2-step** |
| `earnfi_human_test` | Request human testing — **paid 2-step** |
| `earnfi_human_research` | Request focused research — **paid 2-step** |
| `earnfi_human_verify` | Request human verification — **paid 2-step** |
| `earnfi_human_moderate` | Request human moderation — **paid 2-step** |
| `earnfi_human_feedback` | Collect short feedback — **paid 2-step** |
| `earnfi_human_action_result` | Poll normalized Human Action result |
| `earnfi_get_job` | Job status by id (free) |
| `earnfi_list_submissions` | List submissions (free) |
| `earnfi_list_completions` | List completions (free) |
| `earnfi_get_job_detail` | Creator job detail (`agent_token`) |
| `earnfi_get_job_users` | Creator job participants (`agent_token`) |
| `earnfi_get_job_payments` | Creator job payments (`agent_token`) |
| `earnfi_list_contest_submissions` | Contest submissions (`agent_token`) |
| `earnfi_mark_contest_winner` | Mark contest winner (`agent_token`) |
| `earnfi_list_verifications` | List pending verifications (creator) |
| `earnfi_approve_verification` | Approve a verification |
| `earnfi_reject_verification` | Reject a verification |
| `earnfi_pause_job` | Pause or resume a job |
| `earnfi_close_job` | Close job + refund unused slots (Creator Wallet Paid) |

Optional **token-gated** job fields, **Seeker / SGT** targeting (`require_sgt_holder`, `seeker_only`, `target_clients`), Instant Job fields, and **verified X** requirements are documented in the [Agent API](/integrations/agent-api) and [OpenAPI (x402)](/integrations/openapi-x402) spec.

## REST-only alternative

You can skip MCP and use the Agent API directly: first `GET` without payment → **402** → sign → retry with `PAYMENT-SIGNATURE`. MCP wraps the same behavior with structured JSON.
