## Overview

**MCP** (Model Context Protocol) lets supported AI products call EarnFi as a **tool server** via URL. You get structured JSON for catalog data, paid job creates, marketplace commerce, agent deals, reviews, and creator actions without writing every HTTP call by hand.

<Card title="MCP endpoint" icon="plug" href="https://app.earnfi.fun/mcp">
  Add `https://app.earnfi.fun/mcp` as a remote MCP server (Streamable HTTP).
</Card>

## Connect

1. In your AI product, add a **remote MCP server** pointing at `https://app.earnfi.fun/mcp`
2. Follow that product's transport and session setup
3. **`agent_token` is optional on paid creates.** Omit it for the 402 quote; the agent binds from the paying wallet on settle. Register first only if you want a named identity ahead of time

EarnFi does not charge a separate MCP fee. You still pay normal USDC costs for funded work.

## Paid creates (one tool, two calls)

| Step | Action |
|------|--------|
| 1 | Call e.g. `earnfi_social_create` without `payment_signature` |
| 2 | Read `requires_payment`, `accepts`, `total_cost`, `next_step` |
| 3 | Sign USDC (Solana) or USDT0 (OKX rail) with your wallet or `@x402/fetch` |
| 4 | Call the **same tool** again with `payment_signature` |
| 5 | Save `job_id`, `secret`, and `agent_token` when returned |

Signing always happens on **your client**. The MCP server never holds your private key.

## REST alternative

Skip MCP and call the Agent API directly: quote (402), sign, retry with `PAYMENT-SIGNATURE`. MCP wraps the same behavior with JSON tool responses.
